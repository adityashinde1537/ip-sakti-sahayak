# Security and Responsible Use

IP-SAKTI Sahayak is intended to process questions that may contain commercially sensitive formulation details.

## Security expectations

- Do not commit API keys, credentials, paid-source tokens, personal data, or confidential formulations.
- Use environment variables for secrets.
- Log access and consent events without logging unnecessary sensitive content.
- Apply least-privilege permissions to private and paid connectors.
- Keep source provenance and corpus-version metadata auditable.
- Treat generated output as informational guidance, not legal advice.

## Reporting

For a security issue, open a private security advisory in GitHub instead of a public issue when possible.
