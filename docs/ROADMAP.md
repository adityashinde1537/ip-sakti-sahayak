# Roadmap

## Phase 1 — Citation-grounded retrieval MVP

- [x] React web interface
- [x] India / International jurisdiction switch
- [x] formulation-classification service
- [x] IP/regulatory query routing
- [x] curated source registry
- [x] confidence calculation
- [x] safe abstention and human-escalation signal
- [x] PostgreSQL/pgvector production schema
- [ ] ingest full official source text with version metadata
- [ ] hybrid sparse + dense retrieval
- [ ] citation locator verification
- [ ] expert-reviewed evaluation set

## Phase 2 — Knowledge graph + orchestration

- [ ] relational knowledge graph linking formulation categories, IP rights, ABS duties, authorities and source provisions
- [ ] multi-source orchestration for complex questions
- [ ] stronger citation consistency checks
- [ ] source refresh and outdated-guidance detection

## Phase 3 — Expanded multilingual and source access

- [ ] Bhashini text and voice integration
- [ ] broader Indian-language evaluation
- [ ] paid/private source connectors with explicit logged consent
- [ ] facilitator directory and case escalation
- [ ] broader export-market coverage
- [ ] production privacy, audit and security hardening

## Pilot

Pilot with AYUSH startups and IP facilitators, then evaluate answer accuracy, citation correctness, abstention behavior, and multilingual quality before wider release.
